# 🧪 Chemistry Assignment – Table of Contents Design

## 👋 Introduction  
This folder contains **two different Table of Contents (Index Page) designs** created for my Chemistry assignment using Canva.  

Instead of using a common or basic format, I focused on creating something **visually unique, clean, and impactful**.

---

## 🎯 Purpose Behind These Designs  

For this assignment, I intentionally spent extra time (around **2 hours**) designing the index pages to achieve the following:

- ✨ Create a **unique impression** compared to typical submissions  
- 👨‍🏫 Ensure the assignment stands out immediately when viewed  
- 🎨 Apply creativity in academic work  
- 📈 Improve my design and presentation skills  

👉 A well-designed first page can **grab attention instantly**, even before the content is read.

## ⚖️ Comparison & Thought Process  

Instead of making just one design, I created **two different approaches**:

| Aspect          | Design 1 ✅              | Design 2 ✅                |
|----------------|------------------------|--------------------------|
| Style          | Minimal & Formal       | Creative & Modern        |
| Readability    | Very High              | High                     |
| Visual Impact  | Medium                 | Very High                |
| Purpose        | Clean Academic Look    | Eye-catching Impression  |

👉 This helps in understanding the balance between:  
- **Clarity (Design 1)**  
- **Creativity (Design 2)**
